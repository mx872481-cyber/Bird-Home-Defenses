# 🐣 守卫小鸟的家园

一款将英语单词拼写与轻量塔防玩法结合的游戏化学习网页。

## 功能
- 黄色圆形小鸟与紫色杜鹃的简笔画造型
- 拼写答题、鸟蛋攻击、失败反馈与随机异色蛋
- 初中、高中、四级、六级、雅思词库入口
- 粘贴纯文本导入自定义词汇
- 尝试从文字型 PDF 和 Word `.docx` 提取英文单词与中文释义
- 本机学习记录、错词复习、成绩统计和数据备份
- 手机竖屏布局，可部署到 GitHub Pages

## 词库数量说明
当前内置词表仍是小型演示词表，尚未达到正式词库规模。目标容量为：初中 1600、四级 3000、六级 5000、雅思 600；高中词库容量需要后续确认。页面会显示当前词条数与目标数，不会把尚未提供的词条虚报为已完成。

正式发布前，请导入有合法使用权限且经过校对的词库。自动解析 PDF/Word 的结果需要人工核对；扫描图片版 PDF 需要 OCR，本原型不包含 OCR。当前支持 `.docx`，旧版 `.doc` 请另存为 `.docx`。

## 部署
上传 `index.html` 和 `README.md` 到 GitHub 仓库根目录，然后进入 `Settings → Pages`，选择 `Deploy from a branch`、`main` 和 `/(root)`。

## 数据隐私
PDF/Word 解析在浏览器本地进行（解析库由 CDN 加载）；学习数据保存在当前浏览器的 localStorage 中，不会自动跨设备同步。
