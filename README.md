# 守卫小鸟的家园

一个纯前端、手机竖屏优先的游戏化背单词网页。无需安装依赖、无需 API Key，上传到 GitHub Pages 后即可通过链接访问。

## 当前原型功能
- 黄色小鸟与杜鹃的拼写防守小游戏
- 答对发射鸟蛋、答错/超时失败反馈、随机异色蛋
- 初中、高中、四级、六级、雅思演示词库
- 用户粘贴纯文本导入自定义词汇（每行一个词，或 `apple | 苹果`）
- 本机学习记录、错词记录、成绩统计
- 导出本地数据备份
- 作答限时设置
- 手机竖屏布局与系统键盘输入

## 重要说明
内置每类词库目前只是**小型演示词表**，并非完整的初中、高中、CET-4、CET-6 或 IELTS 词库。正式公开前应补充并核对词条来源、准确性和授权许可。
数据保存在当前浏览器的 `localStorage` 中，不会自动跨设备同步。用户清理浏览器数据后记录可能丢失，建议使用“导出学习记录备份”。

## 本地运行
直接用浏览器打开 `index.html` 即可。没有构建步骤。

## 部署到 GitHub Pages
1. 在 GitHub 新建公开仓库，例如 `bird-home-defense`。
2. 上传 `index.html` 和 `README.md` 到仓库根目录。
3. 进入仓库 `Settings` → `Pages`。
4. 在 `Build and deployment` 选择 `Deploy from a branch`。
5. 选择 `main` 分支和 `/(root)` 目录并保存。
6. 等待部署完成，使用 GitHub Pages 显示的网址打开。
7. 用手机浏览器实际测试输入框、系统键盘和动画。

官方文档：https://docs.github.com/en/pages/quickstart
